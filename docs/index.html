What the demo covers

A course journey designed as one system.

Each module remains easy to review independently, while later assignments reuse earlier skills inside a professional Laravel architecture. The final project is the visible result of that progression.

01

PHP to Laravel

Routes, forms, OOP, Composer, MVC, migrations, Eloquent, CRUD, and authentication are presented through the complete 12-module roadmap.

02

API progression

Module 11 moves from static JSON decoding to a normalized API workbench. Module 12A then adds a verified server-side OpenAI request.

03

Hybrid AI workspace

Qwen 3.6 35B A3B, Qwen 3 Coder Next, and OpenAI GPT-OSS 120B run locally through LM Studio. OpenAI GPT-4o mini provides the online mode through the OpenAI API.

04

Security and operations

Laravel owns authentication, authorization, secret handling, rate limits, session controls, audit events, and administrative boundaries.

AI request boundary

One Laravel interface. Two inference paths.

Provider credentials stay on the server. The selected conversation mode determines whether Laravel routes the request to a private local model or to OpenAI GPT-4o mini.

  1. Interface Authenticated Blade UI
  2. Application Laravel AI services
  3. Private path 3 × LM Studio
  4. Online path OpenAI GPT-4o mini
